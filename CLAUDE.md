# PROJECT COMPLEX — заметки для агента

## Что это

Комплексный сервис для vibemodelling. Пользователь моделит промптами и
картинками, под капотом отрабатывают SketchUp / Blender / Rhinoceros, на выходе
— `fbx / skp / 3dm / obj / glb / stl / step`.

## Монорепа

```
apps/web/            веб-морда (Vite + React 19 + TS)
packages/protocol/   общие типы = контракт с будущим gateway
docs/                архитектура, дизайн-язык, дорожная карта
```

npm workspaces. Команды из корня: `npm run dev`, `npm run build`, `npm run typecheck`.

## Жёсткие правила

1. **Никаких прямых fetch/WS из компонентов.** Весь ввод-вывод — через
   `Transport` из `@complex/protocol`. Сейчас реализация — `MockTransport`
   (`apps/web/src/api/mock.ts`), позже появится `WsTransport`. Если для новой
   фичи нужны данные — сначала расширь `Transport`, потом мок, потом UI.
2. **Цвета только через токены** `apps/web/src/styles/tokens.css`. Никаких
   хардкод-`#hex` в компонентах — иначе сломается тёмная тема и белый лейбл.
3. **Стили — CSS Modules.** Tailwind сознательно не используется: дизайн
   плотный и уникальный, утилитарные классы мешают.
4. **Единица измерения — миллиметр** по всему пайплайну.
5. **Строки UI — в `src/i18n/`.** Русский основной, английский словарь рядом.
   Не хардкодь текст в JSX.
6. **Слои сцены именуются по материалу** (кирпич / стекло / бетон / дерево),
   а не по функции — так принято в рабочих файлах проекта.

## Дизайн

См. `docs/DESIGN.md`. Кратко: монохром, `border-radius: 0`, без теней, угловые
засечки, мерные риски, состояния штриховкой, ID-чипы у всего, JetBrains Mono
для служебки и Inter для тела чата.

## Проверка

```
npm run typecheck
npm run build
npm run dev
```

После правок UI — глазами в браузере: вьюпорт крутится, ноды тянутся, чат
стримит, сплиттеры переживают перезагрузку, консоль без ошибок. Отдельно
проверять кириллицу в uppercase-лейблах с трекингом.
