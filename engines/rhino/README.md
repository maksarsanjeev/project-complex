# Мост Rhino

Rhino подключается через **сторонний плагин [rhinomcp](https://github.com/jingcheng-chen/rhinomcp)**
(MIT). Мы его не форкали и не вносили в репозиторий: он ставится как обычный
плагин Rhino, а наш агент говорит с его сокетом.

Почему чужой, а не свой. На июль 2026 у rhinomcp почти тысяча звёзд, коммиты
ежедневные, поддержаны Rhino 8 на Windows и macOS, и — главное — есть авторинг
Grasshopper: добавление компонентов, соединение проводов, управление
параметрами. Написать это с нуля значит потратить месяцы на то, что уже
работает и поддерживается.

## Установка

1. В Rhino: `_PackageManager` → найти **rhinomcp** → установить.
2. Перезапустить Rhino.
3. Выполнить команду `mcpstart`. Плагин поднимет сокет на `127.0.0.1:1999`.

Порт можно сменить переменной `RHINO_MCP_PORT` — её читает и плагин, и наш агент.

Python-часть rhinomcp (сервер MCP для Claude Desktop) **не нужна**: агент
project complex говорит с плагином напрямую.

## Единицы

**Документ Rhino обязан быть в миллиметрах.** Иначе инструменты Rhino не
публикуются модели вовсе, а в чате появляется объяснение.

Так сделано намеренно. Единица документа в Rhino произвольная, и пересчитывать
за пользователя нельзя: он получит модель в чужом масштабе и заметит это позже
всех — когда файл уйдёт в производство. Лучше отказаться сразу и вслух.

Проверить и поправить: `_DocumentProperties` → Units → Model units → Millimeters.

## Проверка

```
_-RunPythonScript (
  import socket, json, struct
  s = socket.create_connection(("127.0.0.1", 1999), 3)
  p = json.dumps({"type": "get_document_summary", "params": {}}).encode()
  s.sendall(struct.pack(">I", len(p)) + p)
  print(s.recv(65536))
)
```

Проще — запустить агента: он сам опросит Rhino каждые пять секунд, и движок
появится в панели веб-морды как `online` с указанием единиц документа.

## Доменные скрипты

В `scripts/` лежат наши наработки, перенесённые из моста
`rhino-mcp-bridge@unified-server`. Транспорт с тех пор сменился на чужой, а
смысл остался:

| Скрипт | Инструмент | Что делает |
|---|---|---|
| `discipline.py` | `rh_discipline_report` | проверка перед сдачей: замкнутость тел, взаимные проникновения, габариты и пропорции |
| `api_docs.py` | `rh_api_docs` | живая подсказка по API из запущенного Rhino — модель перестаёт угадывать сигнатуры |

Скрипт отправляется в Rhino целиком при каждом вызове, состояние между вызовами
не хранится. Так вызов не сломается оттого, что Rhino перезапустили.
