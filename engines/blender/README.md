# Мост Blender

Blender подключается через **сторонний аддон [blender-mcp](https://github.com/ahujasid/blender-mcp)**
(MIT). Мы его не форкали и не вносили в репозиторий: он ставится как обычный
аддон, а наш агент говорит с его сокетом.

Почти двадцать пять тысяч звёзд и живые коммиты — писать своё в таких условиях
было бы упрямством.

## Установка

1. Скачать `addon.py` из репозитория blender-mcp.
2. Blender: `Edit` → `Preferences` → `Add-ons` → `Install from Disk` → выбрать файл.
3. Включить галочку **Interface: Blender MCP**.
4. В 3D-виде открыть боковую панель клавишей `N` → вкладка **BlenderMCP** →
   **Connect to MCP server**.

Аддон поднимет сокет на `127.0.0.1:9876`. Порт меняется переменной `BLENDER_PORT`.

Python-часть blender-mcp (сервер MCP для Claude Desktop) **не нужна**: агент
project complex говорит с аддоном напрямую.

Нужен Blender 3.0 или новее.

## Что аддон умеет — и чего не умеет

Содержательных команд у него четыре: сведения о сцене, сведения об объекте,
снимок вида и выполнение кода Python. **Готовых команд построения нет** — вся
геометрия делается кодом.

Это не упущение аддона, а его устройство: транспорт намеренно простой, а вся
сообразительность на стороне модели. Для нас это означает, что инструмент
`bl_run_python` здесь не запасной выход, а основной рабочий.

## Единицы — главная ловушка

**Внутренняя единица Blender — метр**, а весь пайплайн проекта в миллиметрах.
Расхождение ровно в тысячу раз, и выглядит оно не как ошибка, а как «модель
куда-то пропала»: объект оказывается размером с километр и уезжает за пределы
видимости.

Поэтому каждый размер в генерируемом коде делится на 1000. Куб 1000 мм — это
`size=1.0`, а не `1000.0`. Правило записано прямо в описании инструмента
`bl_run_python`, чтобы оно было перед глазами в момент написания кода, а не в
документации, которую в этот момент никто не открывает.

Проверить после постройки: `bl_object_info` покажет `dimensions`. Для куба
1000 мм там должно быть `1.0`.

## Проверка

```python
import socket, json
s = socket.create_connection(("127.0.0.1", 9876), 3)
s.sendall(json.dumps({"type": "get_scene_info", "params": {}}).encode())
print(s.recv(65536))
```

Проще — запустить агента: он опросит Blender сам, и движок появится в панели
веб-морды как `online`.
