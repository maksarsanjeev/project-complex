# Дизайн-язык

**Technical UI / FUI.** Приборная панель, а не «ещё один дашборд».
Белый фон, чёрный текст, ноль скруглений, ноль теней, всё держится на
хайрлайнах, угловых засечках и типографике.

## Палитра — строго монохром

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#FFFFFF` | фон приложения |
| `--ink` | `#0A0A0A` | текст, линии, акцент |
| `--ink-2` | `rgba(10,10,10,.62)` | вторичный текст |
| `--ink-3` | `rgba(10,10,10,.38)` | микро-лейблы |
| `--line` | `rgba(10,10,10,.14)` | хайрлайны панелей |
| `--line-2` | `rgba(10,10,10,.28)` | активные границы |
| `--fill` | `rgba(10,10,10,.04)` | ховер, зебра |
| `--accent` | `var(--ink)` | акцент = инверсия, не цвет |

Акцент — **инверсия блока** (чёрная плашка, белый текст). Цвет вводится потом
одной правкой `--accent`. Тёмная тема — блок `[data-theme="dark"]`, все
компоненты уже читают только токены.

## Форма

- `border-radius: 0` везде, кроме круглых хэндлов портов в нодовом графе.
- Панели — 1px хайрлайн, без теней.
- **Угловые засечки** `⌐ ¬ L ⌡` на активных блоках вместо подсветки рамки.
- **Мерные риски** вдоль краёв крупных панелей — как на измерительном приборе.
- Фон шелла — едва заметная сетка `graph paper`, во вьюпорте плотнее.

## Типографика

- **JetBrains Mono** — вся служебка: лейблы, числа, ID-чипы, код, ноды.
- **Inter** — только тело сообщений в чате и длинные описания.
- Микро-лейблы: `10px / uppercase / letter-spacing .10em`, цвет `--ink-3`.
- Все числа — `font-variant-numeric: tabular-nums`.
- Единицы (`мм`, `°`, `tri`) — отдельным приглушённым слогом после числа.

## Состояния — штриховкой, не цветом

| Состояние | Приём |
|---|---|
| `idle` | пунктирный контур |
| `running` | бегущая диагональная штриховка |
| `ok` | сплошной 1px контур |
| `error` | инверсия блока |

## Идентификаторы

У всего есть ID-чип в моноширинной рамке: `SES-014`, `JOB-0231`, `ND-07`.
Это и навигация, и характер интерфейса.

## Движение

120 мс, `steps()` там, где нужен «приборный» щелчок. Всё под
`@media (prefers-reduced-motion: reduce)` отключается.

## Иконки

`lucide-react` со `strokeWidth={1}` — совпадает с толщиной хайрлайнов.
Доменные глифы (порты, режимы отображения) — свои, инлайн-SVG.
