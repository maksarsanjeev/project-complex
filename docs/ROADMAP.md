# Дорожная карта

## Этап 1 — веб-морда ✅

Монорепа, `@complex/protocol`, приложение на Vite + React + TS.
Живой 3D-вьюпорт, рабочий нодовый редактор, чат со стримингом, сессии,
аутлайнер сцены, панель инструментов. Данные — `MockTransport`.

## Этап 2 — gateway

- WS + REST сервер, реализующий `Transport` из `@complex/protocol`;
- `WsTransport` в вебе вместо мока (компоненты не трогаем);
- хранилище сессий, очередь задач, стриминг событий.

## Этап 3 — MCP движков

- подключить существующие мосты (SketchUp `:8080`, Blender `:9876`, Rhino `:9890`)
  как MCP-серверы gateway;
- реальное дерево сцены и превью вместо фикстур;
- экспорт в `fbx / skp / 3dm / obj / glb / stl / step`.

## Этап 4 — MCP базы знаний

- архив опыта с выборочной подгрузкой секций;
- карточки сборок;
- нормы как данные + архитектурный валидатор;
- логгер команд моделлера.

## Этап 5 — оркестрация моделей

- подключение по API (Claude, GPT/Codex, Gemini, локальные, gptimage, nano banana 2);
- подключение CLI-агентов (`codex`, `gemini`, `claude`) к мозговому центру;
- цикл построить → отрендерить → раскритиковать → починить.

## Этап 6 — продукт

- авторизация, проекты, мультипользовательность;
- тёмная тема (уже заложена токенами) и белый лейбл под бюро;
- десктоп-обёртка Windows/macOS.
